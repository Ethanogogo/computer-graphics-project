# Computer Graphics Project - SDL Final Composition

## Project Description

This repository contains the SDL implementation for the final composition image of our Computer Graphics project. The SDL program combines the rendered Blender scenes and the OpenGL scene into one framed composition.

## Contents

- SDL source code
- Scene assets
- Final rendered composition image
- Screenshots of the output

## Final Composition

The final image combines:

1. Blender Scene 1
2. Blender Scene 2
3. OpenGL polygon transformation scene

## How to Run

1. Install SDL2.
2. Clone this repository.
3. Open the project in your preferred C/C++ IDE.
4. Compile and run the source code in the `src` folder.
